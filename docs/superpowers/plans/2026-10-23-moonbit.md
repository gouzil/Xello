# MoonBit Implementation Plan

**Goal:** Make `moonbit` a first-class optional caller and callee in Xello.

**Architecture:** Use the MoonBit native C backend, an actual MoonBit runner,
and a MoonBit provider behind the existing `xello.h` C ABI. Compile generated
provider C into a shared library with its own hidden runtime. Use the standard
library for CLI arguments, JSON and UTF-8; C stubs cover filesystem, dynamic
loading and monotonic timing. No new package dependency is needed.

**Approaches:** Native C integrates with every existing provider and runner.
A Wasm or JavaScript host adds a second runtime boundary and is outside this
change. The implementation uses native C on macOS and Linux.

## Scope

- Add MoonBit module/package metadata, provider, runner and native stubs.
- Extend build selection, manifest registration, bridge labels and every
  native runner's language tables and fixed-size language arrays.
- Extend Make, Docker, compile/test/format CI, formatting hooks and both
  README/usage translations. Keep the old benchmark snapshot dated as before.
- Reuse the dynamic matrix tests; cover actual MoonBit export calls, Unicode,
  repeated calls, malformed CLI input, JSON and every matrix edge.

## Review focus

- Missing MoonBit tools: default builds report a skipped language; an explicit
  `--languages moonbit` build fails with an actionable error.
- Native runtime symbols must not interpose between runner and shared provider.
- Copy provider-returned bytes before dropping MoonBit memory or closing a library.
- Read only the manifest's `languages` array; planned languages are unavailable.
- Invalid input must fail before provider calls and must not corrupt JSON output.

## Verification

- macOS arm64, six available languages: `make test` ran 33 tests, with 32
  passing and the Linux-only Kotlin residency test skipped.
- Linux amd64 Docker: the full native build and smoke tests passed; `make test`
  passed all 33 tests. Make command tests reuse the real `setUpClass` build.
- All 81 direct calls and all nine runners' 81-edge matrices passed, together
  with MoonBit fanout and mixed chains from each runner and nine benchmark edges.
- MoonBit ABI passed 400 null, empty and UTF-8 calls; its shared library exports
  only `xello_hello` and `xello_language`.
- Runtime residency regressions passed after reproducing Go unload failures on
  macOS and Kotlin/Native unload failures on Linux. The original macOS C/Go
  fanout passed 80 consecutive runs; Linux Rust matrix passed 10 additional runs.
- Prek checks over every changed/new file, MoonBit/Zig format checks, and
  `git diff --check` passed.

MoonBit JS, Wasm and LLVM backends and Windows are outside this change. Remote
CI was configured but not run. Toolchain upgrades need native-build revalidation.
